# Data dictionary

All records are synthetic and generated by `src/generate_data.py` with seed 42.

## `customers.csv`

| Field | Type | Meaning |
|---|---|---|
| `customer_id` | text | Synthetic, non-identifying primary key |
| `segment` | category | High value, growth, occasional, or new |
| `region` | category | Synthetic commercial region |
| `is_mobile_first` | integer | Simulated behavioral flag (0/1) |
| `prior_90d_orders` | integer | Simulated orders before the experiment |

## `campaigns.csv`

| Field | Type | Meaning |
|---|---|---|
| `campaign_id` | text | Campaign primary key |
| `campaign_name` | text | Human-readable wave name |
| `channel` | category | Paid search, paid social, email, or display |
| `start_date`, `end_date` | date | Simulated flight dates |
| `planned_budget` | decimal | Planning budget in EUR |
| `holdout_share` | decimal | Intended randomized control share |

## `exposures.csv`

| Field | Type | Meaning |
|---|---|---|
| `exposure_id` | text | Assignment row primary key |
| `campaign_id`, `customer_id` | text | Foreign keys |
| `assignment` | category | Randomized treatment or control |
| `impressions`, `clicks` | integer | Treatment delivery outcomes; zero for holdout |
| `converted` | integer | Simulated conversion during measurement window |
| `order_value` | decimal | Observed order value in EUR; zero without conversion |
| `media_cost` | decimal | Allocated campaign ledger cost; zero for control |

## Derived tables

- `campaign_performance.csv`: treatment-only funnel, spend, CPA, and observed ROAS.
- `campaign_incrementality.csv`: treatment/control rates, lift interval, incremental conversions/revenue, and iROAS.
- `budget_recommendation.csv`: current versus constrained scenario allocation.
